Group Project:
Coffee Shop 146

Build a console-based Python program for a coffee shop, and use it to prove you understand the four pillars of OOP — not just recite them.

Console app only No GUI allowed Group project 100 points
01

Project overview

Your group will design a class structure, implement it in Python, test it, and then explain — in your own words — how your code demonstrates each pillar below. The design and the explanation are graded separately, so both need to hold up.

Pillar 01

Encapsulation

Bundle data and behavior together, and protect an object's internal state.

Pillar 02

Inheritance

Share structure across related classes instead of repeating yourself.

Pillar 03

Polymorphism

Let different classes respond to the same call in their own way.

Pillar 04

Abstraction

Expose what an object does, hide how it does it.

Read this twice: the interface must be command-line only. A GUI — even an optional one — is not allowed.

03

What to build — four parts

1

Class design

Produce class-design table(s) covering, for every class:

  • Class name
  • Attributes
  • Methods
  • Parent class, if applicable
  • Purpose
2

Python program

A working implementation that:

  • Uses classes and objects appropriately
  • Demonstrates all four OOP pillars
  • Uses meaningful class, attribute, and method names
  • Produces a clear, correctly formatted receipt
  • Includes comments and documentation
  • Runs without errors

It will be run against the two sample orders below, and then against different customer/order details to check it's genuinely dynamic.

3

OOP documentation

For each of the four pillars, provide:

  • The OOP pillar
  • Class(es) involved
  • A relevant code screenshot
  • A brief explanation of how your code demonstrates it

Explain it in a way that shows your group actually understands the concept in the context of your own code — not a textbook definition.

4

AI use reflection

If AI was used anywhere in the project, name the tool, how it helped, which parts were AI-assisted, and how your group verified the output.

50–100 words

Every member is still responsible for understanding the full submitted code, AI-assisted parts included.
